# القاطع — AL KATTA

**أداة مفتوحة المصدر لإدارة الباندويث على الشبكة المحلية في ويندوز — بديل مجاني لـ SelfishNet.**

[English 🇬🇧](README.md) · [إخلاء المسؤولية](DISCLAIMER.md) · رخصة MIT

</div>

إعادة بناء حديثة لبرنامج SelfishNet بـ **C# / .NET 8 (WPF)** فوق **Npcap** بدل WinPcap الميت.
أداة لإدارة الباندويث على شبكتك المحلية (LAN) عبر ARP: تكتشف الأجهزة، تعرض أساميها، وتحدد
سرعة كل جهاز — مع **حفظ التحديد بحيث ما يروح لحاله**.

> ⚠️ استعملها فقط على شبكة تملكها أو تديرها. اقرأ [DISCLAIMER.md](DISCLAIMER.md).

---

## المميزات

- 🔍 **اكتشاف الأجهزة** عبر فحص ARP سريع للشبكة.
- 🏷️ **أسامي حقيقية**: NetBIOS + Reverse DNS + الشركة المصنّعة (OUI)، نمط NetCut.
- ✏️ **أسامي مخصّصة**: تكتب اسم الجهاز بإيدك — ينحفظ بالـ MAC ويبقى حتى لو تغيّر الـ IP.
- 🎚️ **تحديد لكل جهاز**: حد تنزيل/رفع بالـ Kbps، أو **قطع** الجهاز كلياً.
- 💾 **حفظ دائم**: التحديدات والأسامي في `%AppData%\AlKatta\profiles.json` وتُستعاد تلقائياً.
- 📊 **سرعات مباشرة** لكل جهاز، تتحدّث كل ثانية.
- 🌙 **System tray**: الإغلاق (X) يصغّر البرنامج للـ tray ويبقى شغّالاً؛ دبل-كلك يرجّعه.
- 🌐 **واجهة معرّبة بالكامل** (RTL).

## المتطلبات

- ويندوز 10 / 11
- **.NET 8 SDK** — https://dotnet.microsoft.com/download
- **Npcap** — https://npcap.com
  أثناء التثبيت فعّل خيار **"Install Npcap in WinPcap API-compatible Mode"**.
  (هذا بديل WinPcap وهو سبب استقرار البرنامج على ويندوز 11.)

## البناء والتشغيل

```bash
dotnet build -c Release
```

شغّل الناتج **كمسؤول (Run as administrator)** — ضروري لالتقاط الباكِتس:

```
src/bin/Release/net8.0-windows/AlKatta.exe
```

## الاستعمال

1. اختر **الواجهة** المتصلة بالشبكة من القائمة.
2. اضغط **فحص** — رح تظهر الأجهزة مع الاسم / الشركة / IP / MAC.
3. اكتب الحد بالـ **Kbps** في عمود `↓ حد` و/أو `↑ حد`، فعّل **تفعيل**، واضغط **تطبيق**.
   - `0` = بدون حد · **قطع** = قطع شبه كامل · **تحرير** = إرجاع الجهاز طبيعي فوراً.
4. دبل-كلك على **اسم مخصّص** واكتب اسم الجهاز — بينحفظ تلقائياً.

## ليش هالبناء بيحل مشاكل SelfishNet

- **التعليق على ويندوز 11** → سببه WinPcap. انتقلنا لـ **Npcap** المدعوم رسمياً.
- **التحديد بيروح لحاله** → عالجناه بأمرين:
  1. حلقة إعادة تسميم ثابتة (`ControlEngine.PoisonIntervalMs`، كل 1.5s) تمنع الجهاز من التصحيح.
  2. حفظ دائم بالـ MAC (`ProfileStore`) + إعادة تطبيق تلقائي عند ظهور الجهاز.
- **أسامي الأجهزة** → `NameResolver` يدمج NetBIOS + Reverse DNS + قاعدة OUI.

### أسامي أكمل (اختياري)
نزّل ملف IEEE من https://standards-oui.ieee.org/oui/oui.txt وحطه باسم `oui.txt` جنب الـ exe.

## ملاحظات النسخة الأولى

- تحديد السرعة بأسلوب **token bucket + drop** (TCP بيتأقلم وينزل قرب الحد).
- التمرير حالياً لـ **IPv4** فقط.
- أجهزة ثابتة الـ ARP ممكن تحتاج فاصل تسميم أقصر — عدّل `PoisonIntervalMs`.
